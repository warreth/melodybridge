Your playlists, on your own machine.

MelodyBridge saves the tracks of a Spotify or YouTube playlist, downloads the music through a waterfall of plugins, and turns the result into a playlist your media server understands.

Get started View on GitHub

Self-hosted. Your files stay on your machine.

How it works

  1. 1

    Add a playlist

    Paste a public Spotify or YouTube playlist link. Every track is saved locally.

  2. 2

    Download the music

    The plugin waterfall fetches each track, tags it and checks that the quality is real.

  3. 3

    Publish it

    Write an M3U file or push the playlist straight to Jellyfin.

Features

Fetch playlists

Public Spotify and YouTube playlists, no API key needed. With an account login, private playlists and liked songs too.

Waterfall download

Plugins are tried in order: Lucida, SoundCloud, Internet Archive, then YouTube. The first that finds a good file wins.

Real quality checks

A spectrum check measures what a file really contains and flags tracks that pretend to be 320 kbps.

Consistent tags

Every file gets a unique MELODY_ID plus full title, artist, album and track tags from the playlist data.

Sync modes

Additive keeps removed tracks as history, Mirror matches the source exactly. Per-playlist auto-sync intervals.

Publish

Standard M3U files with metadata, or playlists pushed straight to Jellyfin, favorites included.

Plays well with your setup

MelodyBridge runs in Docker with one command and keeps its state in a single data directory. Point Jellyfin at your music folder, create a sync job, and your playlists stay current on their own. Every page of the web UI is documented in the user guide.
